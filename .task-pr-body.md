### Reasoning

The sidebar now switches the same compact session cards between By project and By directory. Project grouping combines the main checkout and linked worktrees; directory grouping uses each session's actual execution cwd. Both keep the same separate Pinned section and session actions.

Directory selection and binding move to Files and Changes in Explorer. Workspaces and terminals opens the existing global workspace list from Explorer or Open project, including workspaces with no conversation. Browsing a directory and opening a resource preserve the original conversation and execution cwd.

### Goals

- Reuse the existing compact card content and project status icons; retain rename, pin, labels, read, archive, hover and context-menu actions.
- Keep explicit file/Git targets scoped to the selected session and directory.
- Preserve existing workspace, terminal, service and layout ownership.

### Non-goals

Execution-directory switching and new protocol or resource lifecycles are outside this change.
